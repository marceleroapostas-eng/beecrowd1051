\# Beecrowd 1051 - Imposto de Renda



\## Descrição



Este programa resolve o problema 1051 do Beecrowd.



\## Tecnologias utilizadas



\- Java

\- NetBeans

\- Maven



\## Entrada



A entrada contém um valor de ponto flutuante que representa o salário.



\## Saída



O programa apresenta o valor do Imposto de Renda a ser pago.



Caso o salário seja menor ou igual a R$ 2000,00, apresenta:



\*\*Isento\*\*
